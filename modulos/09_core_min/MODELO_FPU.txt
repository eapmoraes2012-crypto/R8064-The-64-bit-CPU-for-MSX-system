FPU DO R8064 NO NUCLEO (REV41, 15/11/2026)
==========================================
Feita a partir da lista de instrucoes enviada pelo autor do projeto + quatro decisoes dele: aritmetica em uma UNIDADE COMPACTA nova dentro do nucleo;
transcendentais e restos em outra etapa; FSTSW grava em F; FIST/FISTP gravam inteiro de 64 bits. O que a lista nao dizia esta marcado [ESCOLHA].

1. HARDWARE
   08_fpu/rtl/fpu_seq.v   nucleo aritmetico compacto de 80 bits (soma, subtracao, multiplicacao, divisao, raiz, comparacao, conversoes). Mesma interface e mesmos
                          resultados, bit a bit, do fpu_alu.v antigo, mas sequencial (um registrador de 68 bits, deslocamentos de 16/4/1, raiz bit a bit) e
                          SEM multiplicador nem divisor proprios: usa o mul_unit e o div_unit do modulo 03 que o nucleo ja tem para MLT/DIV.
   08_fpu/rtl/fpu_unit.v  pilha ST0-ST7 (80 bits), marcas de vazio, palavra de estado e os comandos que o microcodigo dispara.
   No nucleo a FPU entra pelo mesmo caminho de MLT/DIV (a uop espera no estagio M ate a unidade terminar). Uop de 107 bits: [106] fpu.
   Latencia medida do nucleo aritmetico (clocks, min/media/max): soma 3/16/44, multiplicacao 3/18/43, divisao 3/56/95, raiz 3/57/86, comparacao 3,
   inteiro 3/11/24, FLD32/64 3/4/8, FST32/64 3/12/27. A instrucao inteira gasta mais alguns clocks de pipeline.

2. FORMATO E ARREDONDAMENTO
   Registradores de 80 bits no formato estendido do x87 (sinal, expoente de 15 bits, significando de 64 bits com o bit inteiro explicito).
   [ESCOLHA] Palavra de controle FIXA: arredondamento para o mais proximo (empate para o par), precisao de 64 bits, todas as excecoes MASCARADAS:
   a instrucao sempre devolve a resposta padrao do x87 (NaN, infinito, denormal, INDEFINIDO) e so levanta a marca. Nao ha instrucao para mudar isso na lista.
   Nao ha excecao de FPU para a CPU. O fpu_seq aceita os outros modos de arredondamento/precisao (estao nos vetores), so nao ha como seleciona-los ainda.
   Regras herdadas do modelo do modulo 08 (ref/fpref.py): formato nao suportado (nao normalizado, pseudo-NaN...) = IE + INDEFINIDO; "tiny" antes de arredondar;
   com dois NaN fica o de maior significando; denormal na entrada levanta DE.

3. PILHA
   Empilhar decrementa TOP; desempilhar marca o registrador como vazio e incrementa TOP. FINIT esvazia tudo e zera as marcas (nao apaga os dados).
   [ESCOLHA] Ler registrador VAZIO: IE + SF, C1 = 0, e o valor usado e o INDEFINIDO (FFFF C000000000000000); o destino fica marcado como ocupado.
   [ESCOLHA] Empilhar com ST7 ocupado: IE + SF, C1 = 1, e o que entra e o INDEFINIDO.
   C1: "arredondou para cima" nas aritmeticas e conversoes; 0 nas outras (menos o caso de estouro de pilha acima).

4. INSTRUCOES COM MICROCODIGO (34)                                        codigo            efeito
   FLD STn                                                                ED BC 10+n        empilha uma copia de STn
   FXCH STn                                                               ED BC 08+n        troca ST0 com STn
   FSTP STn                                                               ED BC 18+n        STn := ST0; desempilha
   FADD / FSUB / FMUL / FDIV ST0,STn                                      ED BC 00+n / ED 18+n / ED 98+n / ED 88+n      ST0 := ST0 op STn
   FSQRT / FRINT / FCHS / FABS                                            ED 11 / ED BC 43 / ED BC 40 / ED BC 41       ST0 := f(ST0)
   FCOM STn                                                               ED BC 20+n        compara ST0 com STn: C3 C2 C0 = 000 maior, 001 menor, 100 igual, 111 nao ordenado
   FCOPP                                                                  ED 80             compara ST0 com ST1 e desempilha os dois
   FSTSW                                                                  ED 14             F := {S=0, Z=C3, 0, H=0, 0, PV=C2, N=0, C=C0}   (JR Z = igual, JR C = menor, JP PE = nao ordenado)
   FLD1 FLDZ FLDPI FLDL2 FLDLG FLDLN                                      ED BC 42, ED 92, ED 91, ED 86, ED 87, ED 90  empilha 1, 0, pi, log2(10), log10(2), ln(2)
   FINIT                                                                  ED 82
   FILD (QHL)                                                             ED BC 48          empilha o inteiro de 64 bits com sinal de (QHL)
   FLD32 / FLD64 / FLD80 (QHL)                                            ED BC 49 / ED BC 4A / ED 85                 empilha o valor de 32 / 64 / 80 bits (10 bytes) de (QHL)
   FST32 / FST64 / FST80 (QHL)                                            ED BC 4B / ED BC 4D / ED 12                 grava ST0; a pilha fica
   FSP32 / FSP64 / FSTP8 (QHL)                                            ED BC 4C / ED BC 4E / ED 13                 grava ST0 e desempilha
   FIST / FISTP (QHL)                                                     ED 83 / ED 84     grava ST0 arredondado como inteiro de 64 bits (FISTP desempilha);
                                                                                            fora da faixa, NaN ou infinito: IE e grava 8000000000000000
   FLUSH                                                                  ED 94             descarrega a TLB inteira (CR17 := 1) e o pipeline. Privilegiada. [nao e de FPU; veio na lista]
   QHL = HL de 64 bits como endereco. Nas gravacoes com desempilhamento a pilha so anda DEPOIS da escrita: uma falta de pagina reinicia a instrucao sem perda.

5. SEM MICROCODIGO (NOP, ou excecao 7/1 com CR14 bit 2 = 1, para emulacao por software): FCOS, FLN, FREM, FREM1, FSIN, FSINC, FTAN, FYL2P, FYL2X
   (a "outra etapa") e FSAVE / FRSTR (ED AF nn; nao estavam na lista: sem elas uma troca de contexto nao salva a FPU).
