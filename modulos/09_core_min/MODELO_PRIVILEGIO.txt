R8064 PRIVILEGE AND EXCEPTION MODEL (REV40, 15/11/2026; revised in REV43, 16/11/2026)
================================================================
Defined in this revision (the repository did not have this model). Implemented in rtl/r8064_core_min.v and sim/gen_r64_rom.py; tested in sim_r64 (core x model in
Python) and in 13_soc/sim/tb_soc_exc.v (scenarios 9 to 12, with MMU). Everything here is a DESIGN CHOICE: review it and change what does not fit.

1. MODOS
   Two levels: SUPERVISOR (0) and USER (1). After reset the core is in supervisor and NOTHING changes for the existing MSX software, which never leaves it.
   The mode lives in CR18:  bit 0 = U (current mode)   bit 1 = PU (previous mode, saved on exception entry).
   The current mode goes to the MMU (signal cr_mmu_user): a page without the PTE U bit is not accessible in user mode; a page with U is not executable in supervisor.
   CR14 (already existed):   bit 0 = MMU on   bit 1 = U (old way of changing the mode: still accepted on WRITE)   bit 2 = TE (new)   bits 15:8 = ASID.
   TE = "trap enable": enables the illegal instruction (undefined ED opcode) and divide error exceptions. With TE = 0 (reset) they behave as before
   (NOP / fixed result with flags), which is what MSX software expects.

2. EXCEPTION ENTRY (same for all causes; nothing is pushed)
   CR12 := auxiliary value      CR11 := cause      CR13 := EPC      CR18 := {PU = previous mode, U = 0}      mode := supervisor (already at the handler fetch)
   IFF2 := IFF1, IFF1 := 0 (interrupts off)      PC := CR9 (vector; 0040h after reset)

   cause (CR11)                                  CR12 (auxiliary)            EPC (CR13)
   -------------------------------------------   -------------------------   ------------------------------------------
   MMU fault: CR11 = {write[4], data[3],    address that faulted         the instruction that faulted (it is restarted)
                 code[2:0] = 1 to 4}  (already existed)
   0  interrupt accepted in user mode         0                           the next instruction
   5  SCALL n                                    n                           the instruction AFTER the SCALL
   6  divide error (only with TE = 1)            0                           the divide instruction (nothing was changed)
   7  instruction that cannot be executed       0 = illegal ED opcode        the instruction itself
                                                 2 = privileged in user mode
   Cause 7 with auxiliary 0 only happens with TE = 1; with auxiliary 2, always. If more than one condition holds, the order is: privileged, illegal, SCALL.

3. RETURN: SYSRT (ED A4)      mode := PU (CR18 := CR18 >> 1)      IFF1 := IFF2      PC := CR13
   The handler may change CR13 (to skip the instruction) and CR18 (to choose the mode to return to) before SYSRT.
   There is only ONE saved level: before re-enabling interrupts or doing anything that may cause another exception, the handler has to save CR13 and CR18 (and CR11/CR12 if
   needed). The stack is NOT switched: the handler runs with the SP of the interrupted program and must switch on its own (CR0 to CR7 are free for scratch).

4. SYSTEM INSTRUCTIONS
   JP USER,(uu)  ED B4 BC | B5 DE | B6 HL | B7 AX    mode := user; PC := uu.                                                             privileged
   SYSRT         ED A4                               see item 3.                                                                         privileged
   SCALL n       ED 22 n                             system call: exception cause 5 (in any mode).
   PROT 0/1      ED 00 / ED 01                       turns the MMU off / on (CR14 bit 0); the other CR14 bits stay.                    privileged
   RESET         ED 25                               CR14 := 0 (MMU and TE off), CR18 := 0, CR10 := 0 (interrupts off), PC := 0.
                                                     Does NOT clear registers, the other CRs, I, the interrupt mode or EXX.            privileged
   STDBY         ED 24                               waits for an interrupt (repeats itself, like HALT).                              privileged
   WAKE          ED 23                               NOP (there is only one core to wake).                                                 privileged
   SVCTX (uu)    ED AE 08 BC | 0A DE | 0C HL | 0F AX saves the context at (uu): 16 words of 8 bytes, in this order:
   LDCTX (uu)    ED AE 48 BC | 4A DE | 4C HL | 4F AX     AX BC DE HL IX IY SP F N0 N1 N2 N3 N4 N5 N6 N7        (F in the low byte of the 8th word)
                                                     The alternate set (EXX / EX AF) is not included. They are not privileged (they only touch the program's own memory).
                                                     The 128-byte block must be mapped: a fault in the middle of LDCTX restarts the instruction with uu already changed.
   Also privileged: MFCR, MTCR, LDCR, STCR, PGINV and, from the Z80, DI, EI, IM n, LD I,A and all I/O (IN, OUT, INI/IND/INIR/INDR, OUTI/OUTD/OTIR/OTDR).
   NOT privileged: HALT, RETI, RETN, LD A,I, LD A,R, LD R,A.
   All instructions have microcode (the FPU and INW/INL/INQ, OUTW/OUTL/OUTQ came in REV43); only the ED 06/07 encodings (removed), ED 77/7F, FENCE and ISYNC are NOP.

5. INTERRUPCOES
   In supervisor nothing changed (Z80 IM 0/1/2 push the PC; legacy mode jumps to the vector). In user mode the interrupt enters as an EXCEPTION of cause 0
   (the handler runs in supervisor and returns with SYSRT, which re-enables interrupts because IFF2 kept the previous IFF1).

6. MLT, DIV AND DJNZW (requested together)
   MLT (all): Z = zero product; C = the high half of the product is significant (unsigned: nonzero, same as the R800's MULUB/MULUW; signed: different
        from the sign extension of the low half); signed: S = sign of the product and PV = C; unsigned: S = PV = 0. H and N stay as they were; bits 5 and 3 = 0.
   DIV (all): no error: Z = zero quotient, S = sign of the quotient (signed only), PV = C = 0. H and N stay; bits 5 and 3 = 0.
        ERROR (zero divisor or quotient that does not fit): with TE = 0: C = PV = 1, Z = S = 0, quotient = all ones and remainder = low part of the dividend;
        with TE = 1: cause 6 exception and no register or flag changes.
   DJNZW nn: BC (16 bits) := BC - 1, no flags; jumps if BC != 0. (Before it used only B, like DJNZ.)

7. LIMITES CONHECIDOS
   - Writing CR14 or CR18 with LDCR/MTCR changes TE/mode a few clocks later: the instruction right after may still be decoded with the old value.
     To change mode use JP USER, SYSRT or the exception itself (these flush the pipeline). Reading CR14 does not return the mode: use CR18.
   - Only one level of saving (item 3) and no "double fault" detection: an exception inside the handler overwrites CR11/12/13/18.
   - The new exceptions were only simulated in native mode; in the governed timing modes (Z80 / R800) they were not checked.
   - There is no per-port I/O protection: in user mode all I/O is privileged (the system may emulate it in the handler).
