Z80 REFERENCE MODEL (module 12_z80/ref)
============================================
zasm.py     minimal assembler (Python) -> zexdoc.com    : python3 zasm.py zexdoc.z80 zexdoc.com
z80ref.c    C reference model (documented + undocumented, X/Y flags, MEMPTR, R, T-states per instruction)
            gcc -O2 -o z80ref z80ref.c ; ./z80ref zexdoc.com   (CP/M shim: BDOS 2 and 9; jp 0 ends)
            ./z80ref -t  -> tdump.txt (max/min T of each opcode, 7 prefix pages)
cmpt.py     compares tdump.txt with R8064_Z80_instrucoes_fpga.txt
RESULTS: ZEXDOC 67/67 OK (5.76e9 instructions, 46.7e9 T-states = ~3.5 h on a 4 MHz Z80, 0.7 min in C)
            T-states: 1269/1269 opcodes match the table (taken/not-taken, repeats).
LIMITS:   ZEXDOC masks undefined flags (X/Y and others); IN/OUT and interrupts not yet modeled (stub).
           Pure Python would be ~100x slower; the C model is the reference, Python is left for the bus trace.
