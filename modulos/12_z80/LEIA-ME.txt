ARQUIVOS
 rtl/z80_core.v   core (v2, reduced area). One 'ce' pulse = one T-state. Bus with Z80 convention (mreq/rd/wr/iorq/m1/rfsh active at 1 inside the core; z80_top inverts).
 rtl/z80_ce.v     clock-enable generator by phase accumulator: turbo 0/1/2/3 = 3.58 / 7.16 / 14.3 / 28.6 MHz (STEP_BASE parameter for the board clock; default 2^28 = 57.2727 MHz clock; at 57.27 MHz turbo 3 is limited to 14.3 MHz).
                  use_ext=1: uses ce_ext (synchronized to the MSX slot clock). ce pulses always separated by >= 3 clocks.
 rtl/z80_top.v    ce + core, Z80-style ports (a, dout, din, mreq_n, iorq_n, rd_n, wr_n, m1_n, rfsh_n, halt_n, busak_n, wait_n, int_n, nmi_n, busrq_n).
                  msx_w=1 adds 1 wait in M1 and in I/O (MSX behavior). instr_done pulses at the end of each instruction.
 rtl/z80_core_v1_paralelo.v   previous version (larger and faster), kept as a verified reference.
 rtl/z80_msx_*.v, sdram_byte_if.v   integration with MSX memory and SDRAM (see LEIA-ME_msx.txt).
 ref/             assembler (zasm.py), C reference model (z80ref.c), ZEXDOC (zexdoc.z80/.com), T-state tables (tdump.txt, cmpt.py).
 sim/             tb_z80.v + vec/ (vectors generated by gen_vectors.py). rodar_z80.bat = full regression (expected: PASS on all lines).
 pnr/             medir_z80.bat = Yosys + nextpnr (resumo_z80.txt = Fmax; LUT4 and ALU at the end of yosys_z80.log, "Printing statistics").

HOW TO RUN (OSS CAD Suite terminal)
 1) sim\rodar_z80.bat   -> sim\resultado_z80.txt   (r01-r12, zex, wait=1 r01, wait=1 zex: PASS)
 2) pnr\medir_z80.bat   -> pnr\resumo_z80.txt, yosys_z80.log
 To regenerate vectors: python3 sim\gen_vectors.py (needs the model: gcc -O2 -o z80ref ref\z80ref.c).

TIMING MODEL
 M1 = 4 T (6 T on INT acknowledge), MR/MW = 3 T, I/O = 4 T; WAIT sampled at T2 (I/O: T3). MSX: +1 T in M1 and I/O (msx_w). The per-opcode T table matches R8064_Z80_instrucoes_fpga.txt (1269/1269).

KNOWN LIMITS (not verified against real silicon)
 - X/Y flags (bits 5 and 3) and MEMPTR follow the Fuse-style model; ZEXDOC masks these bits, so only the C model confirms them.
 - NMI uses an internal cycle (5 T + push, vector 0066h) without a visible M1 on the bus; INT mode 0 only executes RST (RST-type acknowledge opcode), modes 1 and 2 complete.
 - INIR/OTIR/INDR/OTDR without the "modern" flag effects (extra H/PV) of recent Z80 revisions.
 - HALT out of the random tests (only in r06/r12 and at the end of the vectors).
 - Bus request (busrq/busak) implemented but not exercised in the tests.
