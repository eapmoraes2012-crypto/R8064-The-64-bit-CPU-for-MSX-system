MODULO 06 - CACHE 8 KB I + 8 KB D (cache8k.v, mem_arb.v)
Design: 2 ways, 32 B line (4 64-bit words), BSRAM, write-through + 4-entry write buffer, no write allocate, LRU per set.
Tags+valid in LUTRAM (2 copies), data in 4 BSRAM (SDPX9B) per cache. Invalidation (inv input): 128-clock sweep (cache unavailable during that time); also after reset.
SIMULATION (Icarus; tb_cache.v): D and I simultaneously -> cache8k x2 -> mem_arb -> sdram_ctrl -> sdram_model, shadow memory checks every read and, after draining, the whole SDRAM.
  Hit latency: 1 clock; hit throughput: 1 access/clock (256 reads in 258 clocks); a write takes 2 clocks (1 bubble).
  Read miss latency (accept->data): 31 clocks (D) / 33 clocks (I, waiting for the arbiter) - higher than the 20-25 estimate of 05b (4 64-bit reads in series in the 1-request controller).
  Tests: T1 latencies, T2 throughput, T3 byte-enable/write without allocate, T4/T4b conflict+exact LRU, T5 coherence with inv, T6-T8 random (60k/80k/40k clocks) with 0 errors, 0 SDRAM timing violations.
  Mutants: 8 of 9 killed (lru, drain before fill, byte-enable, way 1 not written, full buffer, inv ignored, valid bit, ...). Survivor: removing s1_ok<=0 at the end of the sweep (corner case: pending read in set 127 during the sweep) - kept for safety, not exercised.
SYNTHESIS/P&R (Yosys synth_gowin + nextpnr, GW2AR-LV18QN88C8/I7, 100 MHz, LFSR wrapper): D cache = 2543 LUT4, 1158 FF, 6 BSRAM (4 data + 2 buffers); Fmax 110.7 MHz (seed 1), 108.1 (seed 2). The wrapper's critical path ends at BSRAM->rdata->parity (wrapper artifact); in the CPU rdata goes into the next stage.
Evolution: v1 (128-bit valid vectors + mux dependent on ready->accept) 86 MHz; v2 (dual A/B read) 71 MHz because yosys merged the reads again; v3 final: valid inside the tag, 2 A/B copies, comparison before the register, a single write port (otherwise the tags become flip-flops: 8240 LUT).
CAVEATS: coherence with Z80/MSX/MMU only through inv (sweep); the I-cache does not see the D writes (needs inv); fixed 19-bit (4 MB) addresses; a read miss serializes 4 64-bit accesses (a burst in the controller would reduce it to ~20 clocks).

4 KB INSTRUCTION CACHE (cache_dm WR=0 IDX=7 STATS=0) - measured by the user 04/11/2026 (Yosys 0.70 + nextpnr, GW2AR-LV18QN88C8/I7):
  LUT1 69 + LUT2 53 + LUT3 75 + LUT4 196 = 393; ALU 11; RAM16SDP4 24 (~96 LUT4 eq.); FF 341; BSRAM 3 (1 DPX9B + 2 SDPX9B). Total ~500 LUT4 eq. (inclui ~50-100 do involucro LFSR).
  Fmax 115.6 MHz (PASS at 100). Note: the old wrapper vanished in synthesis because m_wdata/m_be are left undriven with WR=0 and fed the output parity.
