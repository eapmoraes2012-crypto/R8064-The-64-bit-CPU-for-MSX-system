Compile: cd sim; iverilog -g2012 -o t.vvp tb_msx_mem.v ../rtl/msx_mem.v && vvp t.vvp   (expects "PASS: msx_mem 0 errors")
- Mapper: ports FC,FD,FE,FF = segment of pages 0000,4000,8000,C000 (16 KB). Read returns the value with unused bits as 1. Reset 3,2,1,0.
- MegaRAM ASCII8: 8 KB banks for 4000,6000,8000,A000; a write to 6000-67FF,6800-6FFF,7000-77FF,7800-7FFF chooses the bank.
- Primary slot A8h included (SLOT_MAP=3, SLOT_MEGA=2, parameters). Expanded slots (FFFFh) NOT implemented.
- One instance per core (own registers, physical memory shared by the arbiter). Input 'en' turns the block off (R8064 outside Z80 mode).
ASSUMPTIONS TO CONFIRM: (1) ports FC,FD,FE,FF (the request said FC,FC,FE,FF); (2) MegaRAM write mode via IN/OUT 8Eh; in write mode, writing to 6000-7FFF
 also writes to RAM; (3) default sizes: mapper 1 MB (base 0), MegaRAM 1 MB (base 100000h); fits up to 4 MB / 2 MB by parameter.
Estimated cost (not measured): ~120 LUT4 and ~75 FF per instance, ~240 LUT4 for two cores.
